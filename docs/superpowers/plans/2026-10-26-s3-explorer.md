# S3 탐색기 + 파일 비교 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 리소스 브라우저 옆에 별도 탭으로 S3 탐색기(로컬↔S3 2단 패널, 업로드·다운로드·폴더·이름 변경·삭제)와 파일 비교 탭(Rust `similar` 기반 diff)을 추가한다.

**Architecture:** Rust에 새 `explorer` 모듈(순수 함수 `keys`/`local`/`textfile`/`diff` + S3 쓰기 `s3ops` + 전송 큐 `transfer` + `external`)과 별도 커맨드 파일 `explorer_commands.rs`를 둔다. 프론트엔드는 `src/explorer/`에 패널·전송·비교 컴포넌트를 두고, `App.tsx`에 탭 바를 추가해 탭을 언마운트 없이 전환한다. 전송 진행은 Tauri 이벤트 `transfer-progress`로 받는다.

**Tech Stack:** 기존(Tauri 2, aws-sdk-s3, React 18, TanStack Query 5, Vitest) + Rust `similar` 2, `md-5` 0.10, tokio `fs`/`io-util`.

**Spec:** `docs/superpowers/specs/2026-10-26-s3-explorer-design.md`

## Global Constraints

- 리소스 브라우저 어댑터(`src-tauri/src/adapters/`)는 조회 전용을 유지한다. S3 쓰기 API(PutObject, CopyObject, DeleteObjects)는 `src-tauri/src/explorer/`에서만 호출한다.
- 쓰기는 사용자의 명시적 동작(드롭, 버튼) 뒤에만, 덮어쓰기와 삭제는 확인 창을 거친 뒤에만 일어난다.
- 텍스트 비교 한도: 파일당 2MB(2 * 1024 * 1024 바이트). 바이너리 판별: 앞 8KB에 NUL 바이트가 있거나 전체가 UTF-8이 아님.
- 같은 내용이 20줄을 넘게 이어지면 앞뒤 3줄만 남기고 접는다.
- 전송 동시 실행 수 3. 다운로드 진행 이벤트 간격 512KB. 업로드는 시작/끝 이벤트만.
- 업로드·복사 한도 5GB(5 * 1024^3 바이트). 초과 시 "5GB가 넘는 파일은 아직 업로드할 수 없어요".
- DeleteObjects는 1,000개 단위.
- 숨김 파일(이름이 `.`으로 시작)은 로컬 목록에서 제외. 로컬 목록은 폴더 먼저, 이름순(대소문자 무시).
- 외부 비교 도구 기본값 FileMerge `/usr/bin/opendiff {left} {right}`, VS Code `code --diff {left} {right}`, 사용자 지정은 `{left}`/`{right}` 자리표시자.
- 설정 필드 추가: `explorerLocalPath`, `diffTool`(`"filemerge" | "vscode" | "custom"`), `diffToolCommand` — 모두 없으면 null/기본값으로 기존 설정 파일과 호환.
- UI 문구는 한국어 해요체. 코드 식별자·커밋은 영어. 커밋 끝에 빈 줄 + `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Rust는 `src-tauri/`에서, npm은 저장소 루트에서 실행한다. Rust 툴체인은 `rust-toolchain.toml`(1.96.1).
- AWS SDK getter/builder 시그니처가 계획 코드와 다르면 컴파일러에 맞추되 동작은 유지한다.

```rust
    pub path: String,
    pub is_dir: bool,
    pub size: Option<u64>,
    pub modified: Option<String>,
}

#[serde(rename_all = "lowercase")]
pub enum Direction {
    Upload,
    Download,
}

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct TransferRequest {
    pub id: String,
    pub direction: Direction,
    pub local_path: String,
    pub bucket: String,
    pub region: String,
    pub key: String,

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize)]

    Running,
    Done,
    Failed,
}
```

```rust
pub fn upload_key(dest_prefix: &str, base: &Path, file: &Path) -> String {
    let rel = file.strip_prefix(base).unwrap_or(file);
    let parts: Vec<String> = rel
        .components()
        .map(|c| c.as_os_str().to_string_lossy().into_owned())
        .filter(|p| p != "/")
        .collect();
    format!("{dest_prefix}{}", parts.join("/"))
}

pub fn parent_prefix(key: &str) -> &str {
    let trimmed = key.trim_end_matches('/');
    match trimmed.rfind('/') {
        Some(i) => &key[..=i],
        None => "",
    }
}

pub fn download_path(local_dir: &Path, base_prefix: &str, key: &str) -> Option<PathBuf> {
    let rel = key.strip_prefix(base_prefix).unwrap_or(key);
    let segments: Vec<&str> = rel.split('/').filter(|s| !s.is_empty()).collect();
    if segments.is_empty() || segments.iter().any(|s| *s == ".." || *s == ".") {
        return None;
    }
    let mut path = local_dir.to_path_buf();
    for seg in segments {
        path.push(seg);
    }
    Some(path)
}

pub fn validate_name(name: &str) -> Result<(), AppError> {
    let name = name.trim();
    if name.is_empty() {
        return Err(AppError::other("이름을 입력하세요"));
    }
    if name.contains('/') {
        return Err(AppError::other("이름에 /를 쓸 수 없어요"));
    }
    if name == "." || name == ".." {
        return Err(AppError::other("이 이름은 쓸 수 없어요"));
    }
    Ok(())
}

pub fn rename_target(from: &str, new_name: &str) -> String {
    let parent = parent_prefix(from);
    if from.ends_with('/') {
        format!("{parent}{new_name}/")
    } else {
        format!("{parent}{new_name}")
    }
}

pub fn moved_key(from: &str, to: &str, key: &str) -> String {
    if from.ends_with('/') {
        format!("{to}{}", key.strip_prefix(from).unwrap_or(""))
    } else {
        to.to_string()
    }
}
```

```rust
pub fn list_dir(path: &Path) -> Result<Vec<LocalEntry>, AppError> {
    let read = fs::read_dir(path).map_err(|e| AppError::other(format!("폴더를 열 수 없어요: {e}")))?;
    let mut out = Vec::new();
    for entry in read.flatten() {
        let name = entry.file_name().to_string_lossy().into_owned();
        if is_hidden(&name) {
            continue;
        }
        let Ok(meta) = fs::metadata(entry.path()) else { continue };
        let is_dir = meta.is_dir();
        out.push(LocalEntry {
            name,
            path: entry.path().to_string_lossy().into_owned(),
            is_dir,
            size: (!is_dir).then(|| meta.len()),
            modified: meta.modified().ok().map(system_time_iso),
        });
    }
    out.sort_by(|a, b| b.is_dir.cmp(&a.is_dir).then_with(|| a.name.to_lowercase().cmp(&b.name.to_lowercase())));
    Ok(out)
}

pub fn expand_files(path: &Path) -> Result<Vec<PathBuf>, AppError> {
    let meta = fs::metadata(path).map_err(|e| AppError::other(format!("파일을 읽을 수 없어요: {e}")))?;
    if !meta.is_dir() {
        return Ok(vec![path.to_path_buf()]);
    }
    let mut out = Vec::new();
    let mut stack = vec![path.to_path_buf()];
    while let Some(dir) = stack.pop() {
        let read = fs::read_dir(&dir).map_err(|e| AppError::other(format!("폴더를 열 수 없어요: {e}")))?;
        for entry in read.flatten() {
            if is_hidden(&entry.file_name().to_string_lossy()) {
                continue;
            }
            let Ok(ft) = entry.file_type() else { continue };
            let p = entry.path();
            if ft.is_dir() {
                stack.push(p);
            } else if ft.is_file() || fs::metadata(&p).map(|m| m.is_file()).unwrap_or(false) {
                out.push(p);
            }
        }
    }
    out.sort();
    Ok(out)
}

pub fn md5_file(path: &Path) -> Result<String, AppError> {
    let mut file = fs::File::open(path).map_err(|e| AppError::other(format!("파일을 읽을 수 없어요: {e}")))?;
    let mut hasher = Md5::new();
    let mut buf = vec![0u8; 64 * 1024];
    loop {
        let n = file.read(&mut buf).map_err(|e| AppError::other(format!("파일을 읽을 수 없어요: {e}")))?;
        if n == 0 {
            break;
        }
        hasher.update(&buf[..n]);
    }
    Ok(format!("{:x}", hasher.finalize()))
}
```

```rust
fn push_seg(v: &mut Vec<Segment>, text: &str, emph: bool) {
    if let Some(last) = v.last_mut() {
        if last.emph == emph {
            last.text.push_str(text);
            return;
        }
    }
    v.push(Segment { text: text.to_string(), emph });
}

/// 한 줄 쌍의 글자 단위 차이를 강조 구간으로 만든다.
fn inline(a: &str, b: &str) -> (Vec<Segment>, Vec<Segment>) {
    if a.len() + b.len() > INLINE_MAX {
        return (vec![Segment { text: a.into(), emph: true }], vec![Segment { text: b.into(), emph: true }]);
    }
    let d = SimilarDiff::from_chars(a, b);
    let (mut l, mut r) = (Vec::new(), Vec::new());
    for ch in d.iter_all_changes() {
        match ch.tag() {
            ChangeTag::Equal => {
                push_seg(&mut l, ch.value(), false);
                push_seg(&mut r, ch.value(), false);
            }
            ChangeTag::Delete => push_seg(&mut l, ch.value(), true),
            ChangeTag::Insert => push_seg(&mut r, ch.value(), true),
        }
    }
    (l, r)
}

fn push_replace(rows: &mut Vec<DiffRow>, stats: &mut DiffStats, o: Range<usize>, n: Range<usize>, old: &[&str], new: &[&str]) {
    let pairs = o.len().min(n.len());
    for k in 0..pairs {
        let (a, b) = (o.start + k, n.start + k);
        let (l, r) = inline(old[a], new[b]);
        rows.push(row(RowKind::Replace, line(a + 1, l), line(b + 1, r)));
        stats.changed += 1;
    }
    for a in o.start + pairs..o.end {
        rows.push(row(RowKind::Delete, line(a + 1, plain(old[a])), None));
        stats.removed += 1;
    }
    for b in n.start + pairs..n.end {
        rows.push(row(RowKind::Insert, None, line(b + 1, plain(new[b]))));
        stats.added += 1;
    }
}

fn flush_equal(run: &mut Vec<DiffRow>, out: &mut Vec<DiffRow>) {
    if run.len() > COLLAPSE_MIN {
        let tail = run.split_off(run.len() - CONTEXT);
        let middle = run.split_off(CONTEXT);
        out.append(run);
        out.push(DiffRow { kind: RowKind::Collapsed, left: None, right: None, hidden_rows: middle });
        out.extend(tail);
    } else {
        out.append(run);
    }
}

fn collapse(rows: Vec<DiffRow>) -> Vec<DiffRow> {
    let mut out = Vec::new();
    let mut run = Vec::new();
    for r in rows {
        if r.kind == RowKind::Equal {
            run.push(r);
        } else {
            flush_equal(&mut run, &mut out);
            out.push(r);
        }
    }
    flush_equal(&mut run, &mut out);
    out
}
```

```rust
pub fn build_text_diff(old: &str, new: &str) -> TextDiff {
    let old_lines: Vec<&str> = old.lines().collect();
    let new_lines: Vec<&str> = new.lines().collect();
    let diff = SimilarDiff::configure()
        .timeout(Duration::from_secs(2))
        .diff_slices(&old_lines, &new_lines);
    let ops = diff.ops();
    let mut rows = Vec::new();
    let mut stats = DiffStats::default();
    let mut i = 0;
    while i < ops.len() {
        let (tag, o, n) = ops[i].as_tag_tuple();
        match tag {
            DiffTag::Equal => {
                for (a, b) in o.zip(n) {
                    rows.push(row(RowKind::Equal, line(a + 1, plain(old_lines[a])), line(b + 1, plain(new_lines[b]))));
                }
            }
            DiffTag::Delete => {
                if let Some((DiffTag::Insert, _, n2)) = ops.get(i + 1).map(|op| op.as_tag_tuple()) {
                    push_replace(&mut rows, &mut stats, o, n2, &old_lines, &new_lines);
                    i += 2;
                    continue;
                }
                for a in o {
                    rows.push(row(RowKind::Delete, line(a + 1, plain(old_lines[a])), None));
                    stats.removed += 1;
                }
            }
            DiffTag::Insert => {
                for b in n {
                    rows.push(row(RowKind::Insert, None, line(b + 1, plain(new_lines[b]))));
                    stats.added += 1;
                }
            }
            DiffTag::Replace => push_replace(&mut rows, &mut stats, o, n, &old_lines, &new_lines),
        }
        i += 1;
    }
    let rows = collapse(rows);
    let hunks = hunk_starts(&rows);
    TextDiff { rows, hunks, stats }
}

pub fn meta_verdict(left: &SideMeta, right: &SideMeta) -> Verdict {
    if left.size != right.size {
        return Verdict::Different;
    }
    match (&left.md5, &right.md5) {
        (Some(a), Some(b)) if a == b => Verdict::Same,
        (Some(_), Some(_)) => Verdict::Different,
        _ => Verdict::Unknown,
    }
}

pub fn assemble(left: SideMeta, lc: Content, right: SideMeta, rc: Content) -> DiffResult {
    if let (Content::Text(a), Content::Text(b)) = (&lc, &rc) {
        let d = build_text_diff(a, b);
        return DiffResult {
            left, right, mode: DiffMode::Text, rows: d.rows, hunks: d.hunks, stats: d.stats,
            meta_verdict: None, reason: None,
        };
    }
    let reason = if lc == Content::Binary || rc == Content::Binary { "binary" } else { "tooLarge" };
    let verdict = meta_verdict(&left, &right);
    DiffResult {
        left, right, mode: DiffMode::Meta, rows: Vec::new(), hunks: Vec::new(), stats: DiffStats::default(),
```

```rust
/// 단일 파트 업로드의 ETag만 MD5다("-"가 들어가면 멀티파트).
pub fn etag_md5(etag: Option<&str>) -> Option<String> {
    let e = etag?.trim_matches('"');
    (!e.contains('-') && e.len() == 32).then(|| e.to_ascii_lowercase())
}

/// CopyObject의 CopySource: "버킷/URL 인코딩된 키".
pub fn copy_source(bucket: &str, key: &str) -> String {
    format!("{bucket}/{}", url_encode(key))
}

pub async fn exists(client: &Client, bucket: &str, key: &str) -> Result<bool, AppError> {
    match client.head_object().bucket(bucket).key(key).send().await {
        Ok(_) => Ok(true),
        Err(e) if e.as_service_error().is_some_and(|s| s.is_not_found()) => Ok(false),
        Err(e) => Err(from_sdk(e, "s3:GetObject")),
    }
}

pub async fn prefix_has_objects(client: &Client, bucket: &str, prefix: &str) -> Result<bool, AppError> {
    let out = client
        .list_objects_v2()
        .bucket(bucket)
        .prefix(prefix)
        .max_keys(1)
        .send()
        .await
        .map_err(|e| from_sdk(e, "s3:ListBucket"))?;
    Ok(!out.contents().is_empty())
}

/// prefix 아래 모든 키와 크기(폴더 표시 객체 포함).
pub async fn list_keys(client: &Client, bucket: &str, prefix: &str) -> Result<Vec<(String, i64)>, AppError> {
    let mut out = Vec::new();
    let mut pages = client.list_objects_v2().bucket(bucket).prefix(prefix).into_paginator().send();
    while let Some(page) = pages.next().await {
        let page = page.map_err(|e| from_sdk(e, "s3:ListBucket"))?;
        for o in page.contents() {
            if let Some(k) = o.key() {
                out.push((k.to_string(), o.size().unwrap_or(0)));
            }
        }
    }
    Ok(out)
}

/// 폴더(`/`로 끝남)는 하위 키 전체로, 파일은 HeadObject 크기와 함께 그대로. 중복 제거.
pub async fn expand_keys(client: &Client, bucket: &str, keys: &[String]) -> Result<Vec<(String, i64)>, AppError> {
    let mut out: Vec<(String, i64)> = Vec::new();
    for key in keys {
        if key.ends_with('/') {
            out.extend(list_keys(client, bucket, key).await?);
        } else {
            let head = client
                .head_object()
                .bucket(bucket)
                .key(key)
                .send()
                .await
                .map_err(|e| from_sdk(e, "s3:GetObject"))?;
            out.push((key.clone(), head.content_length().unwrap_or(0)));
        }
    }
    out.sort();
    out.dedup_by(|a, b| a.0 == b.0);
    Ok(out)
}

pub async fn create_folder(client: &Client, bucket: &str, key: &str) -> Result<(), AppError> {
    client
        .put_object()
        .bucket(bucket)
        .key(key)
        .body(ByteStream::from_static(b""))
        .send()
        .await
        .map_err(|e| from_sdk(e, "s3:PutObject"))?;
    Ok(())
}

pub async fn delete_keys(client: &Client, bucket: &str, keys: Vec<String>) -> Result<usize, AppError> {
    let mut deleted = 0;
    let mut failures: Vec<String> = Vec::new();
    for chunk in keys.chunks(DELETE_BATCH) {
        let ids = chunk
            .iter()
            .map(|k| ObjectIdentifier::builder().key(k).build().map_err(|e| AppError::other(e.to_string())))
            .collect::<Result<Vec<_>, _>>()?;
        let delete = Delete::builder()
            .set_objects(Some(ids))
            .quiet(true)
            .build()
            .map_err(|e| AppError::other(e.to_string()))?;
        let out = client
            .delete_objects()
            .bucket(bucket)
            .delete(delete)
            .send()
            .await
            .map_err(|e| from_sdk(e, "s3:DeleteObject"))?;
        let errs = out.errors();
        deleted += chunk.len() - errs.len();
        failures.extend(errs.iter().map(|e| format!("{}: {}", e.key().unwrap_or(""), e.message().unwrap_or(""))));
    }
    if failures.is_empty() {
        Ok(deleted)
    } else {
        Err(AppError::other(format!("{}개를 지우지 못했어요 ({})", failures.len(), failures[0])))
    }
}

/// 복사 후 삭제. 하나라도 복사에 실패하면 원본은 지우지 않는다.
pub async fn rename(client: &Client, bucket: &str, from: &str, to: &str) -> Result<(), AppError> {
    let items = expand_keys(client, bucket, &[from.to_string()]).await?;
    if let Some((k, _)) = items.iter().find(|(_, size)| *size as u64 > MAX_SINGLE_PUT) {
        return Err(AppError::other(format!("5GB가 넘는 파일은 아직 옮길 수 없어요 ({k})")));
    }
    let mut failed = 0;
    for (key, _) in &items {
        let target = moved_key(from, to, key);
        let res = client
            .copy_object()
            .bucket(bucket)
            .copy_source(copy_source(bucket, key))
            .key(&target)
            .send()
            .await;
        if res.is_err() {
            failed += 1;
        }
    }
    if failed > 0 {
        return Err(AppError::other(format!("일부 객체를 옮기지 못했어요 ({failed}개)")));
    }
    delete_keys(client, bucket, items.into_iter().map(|(k, _)| k).collect()).await?;
    Ok(())
}

pub async fn read_side(client: &Client, bucket: &str, key: &str) -> Result<(SideMeta, Content), AppError> {
    let head = client
        .head_object()
        .bucket(bucket)
        .key(key)
        .send()
        .await
        .map_err(|e| from_sdk(e, "s3:GetObject"))?;
    let size = head.content_length().unwrap_or(0).max(0) as u64;
    let meta = SideMeta {
        label: format!("s3://{bucket}/{key}"),
        size,
        modified: Some(dt(head.last_modified())).filter(|s| !s.is_empty()),
        md5: etag_md5(head.e_tag()),
    };
    if size > MAX_TEXT_BYTES {
        return Ok((meta, Content::TooLarge));
    }
    let out = client
        .get_object()
        .bucket(bucket)
        .key(key)
        .send()
        .await
        .map_err(|e| from_sdk(e, "s3:GetObject"))?;
    let bytes = out
        .body
        .collect()
        .await
        .map_err(|e| AppError::Network { message: e.to_string() })?
        .into_bytes()
        .to_vec();
    Ok((meta, classify_bytes(bytes)))
}

/// 외부 비교 도구용 임시 다운로드(진행 이벤트 없음).
pub async fn download_to(client: &Client, bucket: &str, key: &str, dest: &Path) -> Result<(), AppError> {
    let out = client
        .get_object()
        .bucket(bucket)
        .key(key)
        .send()
        .await
        .map_err(|e| from_sdk(e, "s3:GetObject"))?;
    if let Some(parent) = dest.parent() {
        tokio::fs::create_dir_all(parent).await.map_err(|e| AppError::other(e.to_string()))?;
    }
    let mut file = tokio::fs::File::create(dest).await.map_err(|e| AppError::other(e.to_string()))?;
    let mut body = out.body;
    while let Some(chunk) = body.try_next().await.map_err(|e| AppError::Network { message: e.to_string() })? {
        file.write_all(&chunk).await.map_err(|e| AppError::other(e.to_string()))?;
    }
    file.flush().await.map_err(|e| AppError::other(e.to_string()))?;
    Ok(())
}
```

```rust
pub const PROGRESS_STEP: u64 = 512 * 1024;

pub trait ProgressSink: Send + Sync {
    fn emit(&self, ev: TransferEvent);
}

pub fn part_path(dest: &Path) -> PathBuf {
    let mut name = dest.file_name().map(|n| n.to_os_string()).unwrap_or_default();
    name.push(".part");
    dest.with_file_name(name)

pub fn check_upload_size(len: u64) -> Result<(), AppError> {
    if len > MAX_SINGLE_PUT {
        Err(AppError::other("5GB가 넘는 파일은 아직 업로드할 수 없어요"))
    } else {
        Ok(())
    }
}

fn io_err(e: std::io::Error) -> AppError {
    AppError::other(format!("파일 오류: {e}"))
}

pub async fn run(cfg: SdkConfig, req: TransferRequest, sink: Arc<dyn ProgressSink>) {
    let client = Client::new(&cfg);
    let result = match req.direction {
        Direction::Upload => upload(&client, &req, sink.as_ref()).await,
        Direction::Download => download(&client, &req, sink.as_ref()).await,
    };
    match result {
        Ok(total) => sink.emit(TransferEvent::new(&req.id, TransferStatus::Done, total, Some(total))),
        Err(e) => sink.emit(TransferEvent::failed(&req.id, e)),
    }
}

async fn upload(client: &Client, req: &TransferRequest, sink: &dyn ProgressSink) -> Result<u64, AppError> {
    let len = tokio::fs::metadata(&req.local_path).await.map_err(io_err)?.len();
    check_upload_size(len)?;
    sink.emit(TransferEvent::new(&req.id, TransferStatus::Running, 0, Some(len)));
    let body = ByteStream::from_path(&req.local_path)
        .await
        .map_err(|e| AppError::other(format!("파일을 읽을 수 없어요: {e}")))?;
    client
        .put_object()
        .bucket(&req.bucket)
        .key(&req.key)
        .body(body)
        .send()
        .await
        .map_err(|e| from_sdk(e, "s3:PutObject"))?;
    Ok(len)
}

async fn download(client: &Client, req: &TransferRequest, sink: &dyn ProgressSink) -> Result<u64, AppError> {
    let out = client
        .get_object()
        .bucket(&req.bucket)
        .key(&req.key)
        .send()
        .await
        .map_err(|e| from_sdk(e, "s3:GetObject"))?;
    let total = out.content_length().map(|l| l.max(0) as u64);
    let dest = PathBuf::from(&req.local_path);
    if let Some(parent) = dest.parent() {
        tokio::fs::create_dir_all(parent).await.map_err(io_err)?;
    }
    let part = part_path(&dest);
    sink.emit(TransferEvent::new(&req.id, TransferStatus::Running, 0, total));
    let result: Result<u64, AppError> = async {
        let mut file = tokio::fs::File::create(&part).await.map_err(io_err)?;
        let mut body = out.body;
        let (mut done, mut last) = (0u64, 0u64);
        while let Some(chunk) = body.try_next().await.map_err(|e| AppError::Network { message: e.to_string() })? {
            file.write_all(&chunk).await.map_err(io_err)?;
            done += chunk.len() as u64;
            if done - last >= PROGRESS_STEP {
                sink.emit(TransferEvent::new(&req.id, TransferStatus::Running, done, total));
                last = done;
            }
        }
        file.flush().await.map_err(io_err)?;
        Ok(done)
    }
    .await;
    match result {
        Ok(done) => {
            tokio::fs::rename(&part, &dest).await.map_err(io_err)?;
            Ok(done)
        }
        Err(e) => {
            let _ = tokio::fs::remove_file(&part).await;
            Err(e)
        }
    }
}
```

```rust
/// 실행만 하고 기다리지 않는다(종료는 별도 스레드에서 회수).
pub fn spawn(program: &str, args: &[String], tool: &str) -> Result<(), AppError> {
    let candidates: Vec<&str> = if program == "code" { VSCODE_CANDIDATES.to_vec() } else { vec![program] };
    for candidate in candidates {
        match Command::new(candidate).args(args).spawn() {
            Ok(mut child) => {
                std::thread::spawn(move || {
                    let _ = child.wait();
                });
                return Ok(());
            }
            Err(e) if e.kind() == ErrorKind::NotFound => continue,
            Err(e) => return Err(AppError::other(format!("비교 도구를 실행할 수 없어요: {e}"))),
        }
    }
    Err(AppError::other(not_found_message(tool)))
}

pub fn temp_path(file_name: &str) -> PathBuf {
    let nanos = SystemTime::now().duration_since(UNIX_EPOCH).map(|d| d.as_nanos()).unwrap_or(0);
    std::env::temp_dir().join("magic-mirror-diff").join(nanos.to_string()).join(file_name)
}
```

```rust
#[tauri::command]
pub async fn find_conflicts(
    state: State<'_, AppState>,
    profile: String,
    requests: Vec<TransferRequest>,
) -> Result<Vec<String>, AppError> {
    let mut conflicts = Vec::new();
    let mut uploads = Vec::new();
    for r in requests {
        match r.direction {
            Direction::Download => {
                if Path::new(&r.local_path).exists() {
                    conflicts.push(r.id);
                }
            }
            Direction::Upload => uploads.push(r),
        }
    }
    if let Some(first) = uploads.first() {
        let client = s3_client(&state, &profile, &first.region).await?;
        let results = map_concurrent(uploads, |r| {
            let client = client.clone();
            async move { s3ops::exists(&client, &r.bucket, &r.key).await.map(|e| (r.id, e)) }
        })
        .await;
        for res in results {
            let (id, exists) = res?;
            if exists {
                conflicts.push(id);
            }
        }
    }
    Ok(conflicts)
}

pub async fn start_transfers(app: AppHandle, profile: String, requests: Vec<TransferRequest>) -> Result<(), AppError> {

#[tauri::command]
pub async fn s3_rename(
    state: State<'_, AppState>,
    profile: String,
    bucket: String,
    region: String,
    from_key: String,
    new_name: String,
    overwrite: bool,
) -> Result<RenameResult, AppError> {
    keys::validate_name(&new_name)?;
    let target = keys::rename_target(&from_key, new_name.trim());
    if target == from_key {
        return Ok(RenameResult::Done);
    }
    let client = s3_client(&state, &profile, &region).await?;
    let taken = if target.ends_with('/') {
        s3ops::prefix_has_objects(&client, &bucket, &target).await?
    } else {
        s3ops::exists(&client, &bucket, &target).await?
    };
    if taken && !overwrite {
        return Ok(RenameResult::Conflict { target });
    }
    s3ops::rename(&client, &bucket, &from_key, &target).await?;
    Ok(RenameResult::Done)
}

async fn read_ref(state: &AppState, profile: &str, r: &FileRef) -> Result<(textfile::SideMeta, Content), AppError> {
    match r {
        FileRef::Local { path } => {
            let path = PathBuf::from(path);
            tauri::async_runtime::spawn_blocking(move || {
                let (mut meta, content) = textfile::read_local(&path)?;
                if !matches!(content, Content::Text(_)) {
                    meta.md5 = local::md5_file(&path).ok();
                }
                Ok((meta, content))
            })
            .await
            .map_err(|e| AppError::other(e.to_string()))?
        }
        FileRef::S3 { bucket, region, key } => {
            let client = s3_client(state, profile, region).await?;
            s3ops::read_side(&client, bucket, key).await
        }
    }
}

#[tauri::command]
pub async fn diff_files(
    state: State<'_, AppState>,
    profile: String,
    left: FileRef,
    right: FileRef,
) -> Result<DiffResult, AppError> {
    let (mut lm, lc) = read_ref(&state, &profile, &left).await?;
    let (mut rm, rc) = read_ref(&state, &profile, &right).await?;
    // 한쪽만 텍스트로 판정돼 md5가 비어 있으면 메타 비교를 위해 채운다.
    if !matches!(lc, Content::Text(_)) || !matches!(rc, Content::Text(_)) {
        for (meta, r) in [(&mut lm, &left), (&mut rm, &right)] {
            if meta.md5.is_none() {
                if let FileRef::Local { path } = r {
                    meta.md5 = local::md5_file(Path::new(path)).ok();
                }
            }
        }
    }
    Ok(assemble(lm, lc, rm, rc))
}

async fn materialize(state: &AppState, profile: &str, r: &FileRef) -> Result<String, AppError> {
    match r {
        FileRef::Local { path } => Ok(path.clone()),
        FileRef::S3 { bucket, region, key } => {
            let name = key.rsplit('/').next().filter(|n| !n.is_empty()).unwrap_or("object");
            let dest = external::temp_path(name);
            let client = s3_client(state, profile, region).await?;
            s3ops::download_to(&client, bucket, key, &dest).await?;
            Ok(dest.to_string_lossy().into_owned())
        }
    }
}
```

```ts
import type { S3Entry } from "../api/types";
import type { FileRef, LocalEntry, S3Location } from "./types";

export interface SelectionState {
  selected: string[];
  anchor: string | null;
}

export function nextSelection(
  state: SelectionState,
  clicked: string,
  order: string[],
  mods: { meta: boolean; shift: boolean },
): SelectionState {
  if (mods.shift && state.anchor && order.includes(state.anchor)) {
    const a = order.indexOf(state.anchor);
    const b = order.indexOf(clicked);
    const [from, to] = a <= b ? [a, b] : [b, a];
    return { selected: order.slice(from, to + 1), anchor: state.anchor };
  }
  if (mods.meta) {
    const has = state.selected.includes(clicked);
    return { selected: has ? state.selected.filter((x) => x !== clicked) : [...state.selected, clicked], anchor: clicked };
  }
  return { selected: [clicked], anchor: clicked };
}

interface CompareInput {
  local: LocalEntry[];
  s3: S3Entry[];
  s3Location: S3Location | null;
  focused: "local" | "s3";
}

export function compareTargets({ local, s3, s3Location, focused }: CompareInput): [FileRef, FileRef] | null {
  const toLocal = (e: LocalEntry): FileRef => ({ source: "local", path: e.path });
  const toS3 = (e: S3Entry): FileRef | null =>
    s3Location ? { source: "s3", bucket: s3Location.bucket, region: s3Location.region, key: e.key } : null;
  const filesOnly = local.every((e) => !e.isDir) && s3.every((e) => !e.isFolder);
  if (!filesOnly) return null;
  if (local.length === 1 && s3.length === 1) {
    const right = toS3(s3[0]);
    return right ? [toLocal(local[0]), right] : null;
  }
  if (focused === "local" && local.length === 2) return [toLocal(local[0]), toLocal(local[1])];
  if (focused === "s3" && s3.length === 2) {
    const a = toS3(s3[0]);
    const b = toS3(s3[1]);
    return a && b ? [a, b] : null;
  }
  return null;
}
```

```ts
import { useCallback, useEffect, useRef, useState } from "react";
import { explorerApi, onTransferProgress } from "./api";
import type { TransferEvent, TransferRequest } from "./types";

export interface TransferItem {
  request: TransferRequest;
  event: TransferEvent;
}

const queued = (id: string): TransferEvent => ({ id, status: "queued", transferred: 0, total: null, error: null });

export function useTransfers(profile: string | null, onSettled: (req: TransferRequest) => void) {
  const [items, setItems] = useState<TransferItem[]>([]);
  const itemsRef = useRef<TransferItem[]>([]);
  const settledRef = useRef(onSettled);
  settledRef.current = onSettled;

  const apply = (next: TransferItem[]) => {
    itemsRef.current = next;
    setItems(next);
  };

  useEffect(() => {
    let unlisten: (() => void) | null = null;
    let cancelled = false;
    void onTransferProgress((ev) => {
      const current = itemsRef.current;
      const item = current.find((i) => i.request.id === ev.id);
      if (!item) return;
      apply(current.map((i) => (i.request.id === ev.id ? { ...i, event: ev } : i)));
      if (ev.status === "done") settledRef.current(item.request);
    }).then((fn) => {
      if (cancelled) fn();
      else unlisten = fn;
    });
    return () => {
      cancelled = true;
      unlisten?.();
    };
  }, []);

  const enqueue = useCallback(
    async (requests: TransferRequest[]) => {
      if (!profile || requests.length === 0) return;
      apply([...itemsRef.current, ...requests.map((request) => ({ request, event: queued(request.id) }))]);
      await explorerApi.startTransfers(profile, requests);
    },
    [profile],
  );

  const retry = useCallback(
    async (id: string) => {
      const item = itemsRef.current.find((i) => i.request.id === id);
      if (!profile || !item) return;
      apply(itemsRef.current.map((i) => (i.request.id === id ? { ...i, event: queued(id) } : i)));
      await explorerApi.startTransfers(profile, [item.request]);
    },
    [profile],
  );

  const clearFinished = useCallback(() => {
    apply(itemsRef.current.filter((i) => i.event.status !== "done"));
  }, []);

  return { items, enqueue, retry, clearFinished };
}

export type Transfers = ReturnType<typeof useTransfers>;
```

```tsx
import { useMemo, useRef, useState, type KeyboardEvent, type PointerEvent } from "react";
import type { Column, Resource } from "../api/types";
import { Cell } from "../components/Cell";
import { compareValues } from "../lib/format";
import { nextSelection, type SelectionState } from "./selection";

const DRAG_THRESHOLD = 5;

interface Props {
  columns: Column[];
  rows: Resource[];
  filter: string;
  selection: SelectionState;
  onSelectionChange: (s: SelectionState) => void;
  onOpen: (id: string) => void;
  onBack?: () => void;
  onDragStart?: (ids: string[], point: { clientX: number; clientY: number }) => void;
  emptyText?: string;
}

export function FileTable({ columns, rows, filter, selection, onSelectionChange, onOpen, onBack, onDragStart, emptyText }: Props) {
  const [sort, setSort] = useState<{ key: string; dir: 1 | -1 }>({ key: columns[0]?.key ?? "", dir: 1 });
  const press = useRef<{ id: string; x: number; y: number; started: boolean } | null>(null);

  const visible = useMemo(() => {
    const f = filter.trim().toLowerCase();
    const filtered = f ? rows.filter((r) => r.name.toLowerCase().includes(f)) : rows;
    return [...filtered].sort((a, b) => compareValues(a.values[sort.key] ?? "", b.values[sort.key] ?? "") * sort.dir);
  }, [rows, filter, sort]);
  const order = visible.map((r) => r.id);

  const onKeyDown = (e: KeyboardEvent) => {
    if (e.key === "Backspace") {
      e.preventDefault();
      onBack?.();
      return;
    }
    if (e.key === "Enter") {
      if (selection.selected.length === 1) onOpen(selection.selected[0]);
      return;
    }
    if (e.key !== "ArrowDown" && e.key !== "ArrowUp") return;
    e.preventDefault();
    const current = selection.anchor ? order.indexOf(selection.anchor) : -1;
    const next = e.key === "ArrowDown" ? Math.min(order.length - 1, current + 1) : Math.max(0, current - 1);
    if (order[next]) onSelectionChange({ selected: [order[next]], anchor: order[next] });
  };

  const onPointerDown = (id: string, e: PointerEvent) => {
    if (e.button !== 0) return;
    press.current = { id, x: e.clientX, y: e.clientY, started: false };
  };

  const onPointerMove = (e: PointerEvent) => {
    const p = press.current;
    if (!p || p.started || e.buttons !== 1) return;
    if (Math.abs(e.clientX - p.x) + Math.abs(e.clientY - p.y) < DRAG_THRESHOLD * 2) return;
    p.started = true;
    const ids = selection.selected.includes(p.id) ? selection.selected : [p.id];
    onDragStart?.(ids, { clientX: e.clientX, clientY: e.clientY });
  };

  return (
    <div className="tbl" tabIndex={0} onKeyDown={onKeyDown} data-testid="file-table" onPointerUp={() => (press.current = null)}>
      <table>
        <thead>
          <tr>
            {columns.map((c) => (
              <th
                key={c.key}
                onClick={() => setSort((s) => (s.key === c.key ? { key: c.key, dir: s.dir === 1 ? -1 : 1 } : { key: c.key, dir: 1 }))}
              >
                {c.label} {sort.key === c.key ? (sort.dir === 1 ? "▲" : "▼") : ""}
              </th>
            ))}
          </tr>
        </thead>
        <tbody>
          {visible.map((r) => {
            const on = selection.selected.includes(r.id);
            return (
              <tr
                key={r.id}
                className={on ? "on" : undefined}
                aria-selected={on}
                onClick={(e) => onSelectionChange(nextSelection(selection, r.id, order, { meta: e.metaKey, shift: e.shiftKey }))}
                onDoubleClick={() => onOpen(r.id)}
                onPointerDown={(e) => onPointerDown(r.id, e)}
                onPointerMove={onPointerMove}
              >
                {columns.map((c) => (
                  <td key={c.key}>
                    <Cell kind={c.kind} value={r.values[c.key]} />
                  </td>
                ))}
              </tr>
            );
          })}
        </tbody>
      </table>
      {visible.length === 0 && <div className="empty small">{emptyText ?? "표시할 항목이 없어요"}</div>}
    </div>
  );
}
```

```ts
export function useLocalHome() {
  return useQuery({ queryKey: ["localHome"], queryFn: explorerApi.localHome, staleTime: Infinity });

export function useLocalList(path: string | null) {
  return useQuery({
    queryKey: ["local", path],
    queryFn: () => explorerApi.localList(path!),
    enabled: !!path,
    staleTime: Infinity,
    retry: false,
  });
}

export function parentDir(path: string): string {
  const trimmed = path.replace(/\/+$/, "");
  const i = trimmed.lastIndexOf("/");
  return i <= 0 ? "/" : trimmed.slice(0, i);
```

```tsx
export function S3Pane(p: Props) {

                ›{" "}

                  {s.label}
                </button>
              </span>
            ))}
          </>

function BucketList(p: Props) {
  const q = useResources(p.profile, p.region, p.s3Service, "buckets");
  const items = q.data?.items ?? [];
  const open = (id: string) => {
    const b = items.find((r) => r.id === id);
    if (b) p.onLocationChange({ bucket: b.id, region: b.values.region || p.region, prefix: "" });
  };
  if (q.isError && !q.data) return <ErrorState error={q.error} profile={p.profile} onRetry={p.onRefresh} />;
  if (q.isPending) return <div className="empty">불러오는 중…</div>;
  const columns = p.s3Service.types.find((t) => t.id === "buckets")?.columns ?? S3_COLUMNS;
  return (
    <FileTable
      columns={columns}
      rows={items}
      filter={p.filter}
      selection={{ selected: [], anchor: null }}
      onSelectionChange={() => {}}
      onOpen={open}
      emptyText="버킷이 없어요"
    />
  );
}

function ObjectList(p: Props & { location: S3Location; up: () => void }) {
  const { location } = p;
  const q = useS3Objects(p.profile, location.region, location.bucket, location.prefix);
  const entries = q.data?.pages.flatMap((page) => page.entries) ?? [];
  const open = (key: string) => {
    const e = entries.find((x) => x.key === key);
    if (e?.isFolder) p.onLocationChange({ ...location, prefix: e.key });
  };
  if (q.isError && !q.data) return <ErrorState error={q.error} profile={p.profile} onRetry={p.onRefresh} />;
  if (q.isPending) return <div className="empty">불러오는 중…</div>;
  return (
```

```ts
import { useCallback, useEffect, useRef, useState } from "react";

export type Pane = "local" | "s3";

export interface DragState {
  from: Pane;
  ids: string[];
  x: number;
  y: number;
  over: Pane | null;
}

export function paneAt(x: number, y: number): Pane | null {
  const el = document.elementFromPoint(x, y);
  const pane = el?.closest("[data-pane]")?.getAttribute("data-pane");
  return pane === "local" || pane === "s3" ? pane : null;
}

export function usePaneDrag(onDrop: (from: Pane, to: Pane, ids: string[]) => void) {
  const [drag, setDrag] = useState<DragState | null>(null);
  const dragRef = useRef<DragState | null>(null);
  const dropRef = useRef(onDrop);
  dropRef.current = onDrop;

  const update = (next: DragState | null) => {
    dragRef.current = next;
    setDrag(next);
  };

  const start = useCallback((from: Pane, ids: string[], point: { clientX: number; clientY: number }) => {
    update({ from, ids, x: point.clientX, y: point.clientY, over: null });
  }, []);

  const dragging = drag !== null;
  useEffect(() => {
    if (!dragging) return;
    const move = (e: MouseEvent) => {
      const d = dragRef.current;
      if (d) update({ ...d, x: e.clientX, y: e.clientY, over: paneAt(e.clientX, e.clientY) });
    };
    const up = (e: MouseEvent) => {
      const d = dragRef.current;
      update(null);
      const to = paneAt(e.clientX, e.clientY);
      if (d && to && to !== d.from) dropRef.current(d.from, to, d.ids);
    };
    window.addEventListener("pointermove", move);
    window.addEventListener("pointerup", up);
    return () => {
      window.removeEventListener("pointermove", move);
      window.removeEventListener("pointerup", up);
    };
  }, [dragging]);

  return { drag, start };
}
```

```tsx
        else if (payload.type === "leave") setFinderOver(false);
        else if (payload.type === "drop") {
          setFinderOver(false);
          if (overS3 && payload.paths?.length) handlers.current.uploadPaths(payload.paths);
        }
      })
      .then((fn) => {
        if (cancelled) fn();
        else unlisten = fn;
      });
    return () => {
      cancelled = true;
      unlisten?.();
    };
  }, [p.active]);

  useEffect(() => {
    if (!p.active) return;
    const onKeyDown = (e: KeyboardEvent) => {
      if (dialog) return;
      const tag = (document.activeElement as HTMLElement | null)?.tagName;
      if (tag === "INPUT" || tag === "TEXTAREA") return;
      if (e.key === "Tab") {
        e.preventDefault();
        setFocused((f) => (f === "local" ? "s3" : "local"));
      } else if (e.metaKey && e.key.toLowerCase() === "d") {
        e.preventDefault();
        handlers.current.compare();
      } else if (e.metaKey && e.key === "Backspace" && focused === "s3") {
        e.preventDefault();
        handlers.current.remove();
      }
    };
    window.addEventListener("keydown", onKeyDown);
    return () => window.removeEventListener("keydown", onKeyDown);
  }, [p.active, dialog, focused]);

  if (!p.profile || !p.s3Service) return <div className="empty">프로필을 고르세요</div>;

  return (
    <div className="explorer">
      <div className="panes">
        {localPath ? (
          <LocalPane
            path={localPath}
            onPathChange={changeLocalPath}
            filter={focused === "local" ? p.filter : ""}
            selection={localSel}
            onSelectionChange={setLocalSel}
            focused={focused === "local"}
            onFocus={() => setFocused("local")}
            onDragStart={(ids, pt) => start("local", ids, pt)}
            dropActive={drag?.from === "s3" && drag.over === "local"}
          />
        ) : (
          <section className="pane" data-pane="local">
            <div className="empty">불러오는 중…</div>
          </section>
        )}
        <S3Pane
          profile={p.profile}
          region={p.region}
          s3Service={p.s3Service}
          location={location}
          onLocationChange={changeLocation}
          filter={focused === "s3" ? p.filter : ""}
          selection={s3Sel}
          onSelectionChange={setS3Sel}
          focused={focused === "s3"}
          onFocus={() => setFocused("s3")}
          onDragStart={(ids, pt) => start("s3", ids, pt)}
          dropActive={finderOver || (drag?.from === "local" && drag.over === "s3")}
          onNewFolder={newFolder}
          onRename={rename}
          onDelete={remove}
          onRefresh={p.onRefresh}
        />
      </div>
      <div className="actions">
        <button className="btn small" disabled={!location || localSel.selected.length === 0} onClick={() => uploadPaths(localSel.selected)}>
          복사 →
        </button>
        <button className="btn small" disabled={!location || s3Sel.selected.length === 0} onClick={() => downloadKeys(s3Sel.selected)}>
          ← 복사
        </button>
        <button className="btn small primary" disabled={!targets} onClick={compare}>
          비교 ⌘D
        </button>
        {notice && <span className="err">{notice}</span>}
      </div>
      <TransferQueue items={p.transfers.items} onRetry={(id) => void p.transfers.retry(id)} onClear={p.transfers.clearFinished} />
      {drag && (
        <div className="drag-chip" style={{ left: drag.x + 12, top: drag.y + 12 }}>
          {drag.ids.length === 1 ? lastName(drag.ids[0]) : `${drag.ids.length}개`} {drag.from === "local" ? "→ S3" : "→ 로컬"}
        </div>
      )}
      {dialog && <ConfirmDialog key={dialog.title + (dialog.error ?? "")} {...dialog} onResult={(v, t) => void dialog.onResult(v, t)} />}
    </div>
  );
}
```

```tsx
import { useQuery } from "@tanstack/react-query";
import { Fragment, useEffect, useRef, useState } from "react";
import { errorMessage } from "../api/errors";
import { ErrorState } from "../components/ErrorState";
import { formatBytes, formatDate } from "../lib/format";
import { explorerApi } from "./api";
import { ConfirmDialog } from "./ConfirmDialog";
import { refKey, refLabel } from "./rows";
import type { DiffLine, DiffResult, DiffRow, DiffTool, FileRef, TransferRequest } from "./types";
import type { Transfers } from "./useTransfers";

interface Props {
  profile: string | null;
  left: FileRef;
  right: FileRef;
  active: boolean;
  transfers: Transfers;
  diffTool: DiffTool;
  diffToolCommand: string | null;
}

const VERDICT = { same: "같은 파일로 보여요", different: "두 파일이 달라요", unknown: "같은지 판단할 수 없어요" } as const;
const REASON = {
  binary: "바이너리 파일이라 내용 대신 정보만 비교해요",
  tooLarge: "2MB가 넘어서 내용 대신 정보만 비교해요",
} as const;

function Line({ line }: { line: DiffLine | null }) {
  if (!line) return <div className="dcell empty-cell" />;
  return (
    <div className="dcell">
      <span className="ln">{line.no}</span>
      <span className="code">
        {line.segments.map((s, i) => (
          <span key={i} className={s.emph ? "emph" : undefined}>
            {s.text}
          </span>
        ))}
      </span>
    </div>
  );
}

function RowView({ row }: { row: DiffRow }) {
  return (
    <>
      <Line line={row.left} />
      <Line line={row.right} />
    </>
  );
}

export function DiffTab({ profile, left, right, active, transfers, diffTool, diffToolCommand }: Props) {
  const q = useQuery<DiffResult>({
    queryKey: ["diff", profile, refKey(left), refKey(right)],
    queryFn: () => explorerApi.diffFiles(profile!, left, right),
    enabled: !!profile,
    staleTime: Infinity,
    retry: false,
  });
  const [expanded, setExpanded] = useState<Set<number>>(new Set());
  const [current, setCurrent] = useState(-1);
  const [notice, setNotice] = useState<string | null>(null);
  const [confirm, setConfirm] = useState<{ message: string; request: TransferRequest } | null>(null);
  const rowRefs = useRef<Map<number, HTMLDivElement>>(new Map());
  const hunks = q.data?.hunks ?? [];

  const go = (dir: 1 | -1) => {
    if (hunks.length === 0) return;
    const next = current < 0 ? (dir === 1 ? 0 : hunks.length - 1) : (current + dir + hunks.length) % hunks.length;
    setCurrent(next);
    rowRefs.current.get(hunks[next])?.scrollIntoView?.({ block: "center" });
  };
  const goRef = useRef(go);
  goRef.current = go;

  useEffect(() => {
    if (!active) return;
    const onKeyDown = (e: KeyboardEvent) => {
      if (e.key !== "F7") return;
      e.preventDefault();
      goRef.current(e.shiftKey ? -1 : 1);
    };
    window.addEventListener("keydown", onKeyDown);
    return () => window.removeEventListener("keydown", onKeyDown);
  }, [active]);

  const localRef = left.source === "local" ? left : right.source === "local" ? right : null;
  const s3Ref = left.source === "s3" ? left : right.source === "s3" ? right : null;
  const transferTo = (direction: "upload" | "download") => {
    if (!localRef || localRef.source !== "local" || !s3Ref || s3Ref.source !== "s3") return;
    const request: TransferRequest = {
      id: crypto.randomUUID(),
      direction,
      localPath: localRef.path,
      bucket: s3Ref.bucket,
      region: s3Ref.region,
      key: s3Ref.key,
    };
    const target = direction === "upload" ? refLabel(s3Ref) : localRef.path;
    setConfirm({ message: `${target}을(를) 덮어쓸까요?`, request });
  };

  const openExternal = () => {
    if (!profile) return;
    setNotice(null);
    explorerApi.openExternalDiff(profile, left, right, diffTool, diffToolCommand).catch((e) => setNotice(errorMessage(e)));
  };

  const d = q.data;
  const sameText = d?.mode === "text" && d.stats.added + d.stats.removed + d.stats.changed === 0;

  return (
    <div className="diff">
      <div className="diff-head">
        {d?.mode === "text" && (
          <span className="stats">
            +{d.stats.added} −{d.stats.removed} ~{d.stats.changed}
          </span>
        )}
        <button className="btn small" disabled={hunks.length === 0} onClick={() => go(-1)}>
          ▲ 이전
        </button>
        <button className="btn small" disabled={hunks.length === 0} onClick={() => go(1)}>
          ▼ 다음
        </button>
        <span className="sp">
          {localRef && s3Ref && (
            <>
              <button className="btn small" onClick={() => transferTo("download")}>
                ← 로컬로 내려받기
              </button>
              <button className="btn small" onClick={() => transferTo("upload")}>
                S3로 업로드 →
              </button>
            </>
          )}
          <button className="btn small" onClick={openExternal}>
            외부 도구로 열기
          </button>
        </span>
      </div>
      {notice && <div className="error-banner">{notice}</div>}
      {q.isError && !d ? (
        <ErrorState error={q.error} profile={profile ?? ""} onRetry={() => void q.refetch()} />
      ) : !d ? (
        <div className="empty">비교하는 중…</div>
      ) : (
        <>
          <div className="diff-sides">
            {[d.left, d.right].map((s) => (
              <div key={s.label} className="diff-side">
                <b className="mono">{s.label}</b>
                <span className="dim">
                  {" "}
                  · {formatBytes(s.size)}
                  {s.modified ? ` · ${formatDate(s.modified)}` : ""}
                </span>
              </div>
            ))}
          </div>
          {d.mode === "meta" ? (
            <div className="meta-compare">
              <p className={d.metaVerdict === "different" ? "err" : undefined}>{VERDICT[d.metaVerdict ?? "unknown"]}</p>
              {d.reason && <p className="dim">{REASON[d.reason]}</p>}
              <table>
                <tbody>
                  <tr>
                    <th>크기</th>
                    <td>{formatBytes(d.left.size)}</td>
                    <td>{formatBytes(d.right.size)}</td>
                  </tr>
                  <tr>
                    <th>수정일</th>
                    <td>{d.left.modified ? formatDate(d.left.modified) : "—"}</td>
                    <td>{d.right.modified ? formatDate(d.right.modified) : "—"}</td>
                  </tr>
                  <tr>
                    <th>MD5</th>
                    <td className="mono">{d.left.md5 ?? "—"}</td>
                    <td className="mono">{d.right.md5 ?? "—"}</td>
                  </tr>
                </tbody>
              </table>
            </div>
          ) : (
            <div className="diff-body">
              {sameText && <div className="notice">두 파일이 같아요</div>}
              {d.rows.map((row, i) => (
                <Fragment key={i}>
                  {row.kind === "collapsed" ? (
                    expanded.has(i) ? (
                      row.hiddenRows.map((h, j) => (
                        <div key={`${i}-${j}`} className="drow k-equal">
                          <RowView row={h} />
                        </div>
                      ))
                    ) : (
                      <div className="drow k-collapsed" ref={(el) => el && rowRefs.current.set(i, el)}>
                        <button className="link" onClick={() => setExpanded((prev) => new Set(prev).add(i))}>
                          … {row.hiddenRows.length}줄 같음
                        </button>
                      </div>
                    )
                  ) : (
                    <div
                      data-testid={`drow-${i}`}
                      className={`drow k-${row.kind}${hunks[current] === i ? " current" : ""}`}
                      ref={(el) => el && rowRefs.current.set(i, el)}
                    >
                      <RowView row={row} />
                    </div>
                  )}
                </Fragment>
              ))}
            </div>
          )}
        </>
      )}
      {confirm && (
        <ConfirmDialog
          title="덮어쓸까요?"
          message={confirm.message}
          actions={[{ label: "덮어쓰기", value: "ok", danger: true }]}
          onResult={(value) => {
            const req = confirm.request;
            setConfirm(null);
            if (value === "ok") void transfers.enqueue([req]);
          }}
        />
      )}
    </div>
  );
}
```
