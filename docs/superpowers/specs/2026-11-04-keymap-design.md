# 키맵(단축키) 설계

## 목표
- 앱 전체 단축키를 한곳에서 정의하고, 화면은 "이 범위에서 이 동작"만 등록한다(VS Code의 명령 + 키 바인딩 + `when` 조건 방식).
- ⌘K와 ⌘F의 역할을 나눈다. ⌘K는 앱 전체 리소스 찾기, ⌘F는 지금 보는 목록 안에서만 찾기.
- 지금 보이는 화면에서 쓸 수 있는 단축키를 앱 안에서 볼 수 있게 한다.

## 사용자 결정 (2026-11-04)
- 바인딩은 VS Code 방식으로 정의하되 처음에는 고정한다(사용자가 바꾸는 기능 없음). 정의가 한 표에 모여 있어 나중에 설정에서 바꾸기를 더하기 쉽다.
- ⌘F: 목록 검색칸을 평소에는 숨긴다. ⌘F를 누르면 지금 보는 목록 안쪽 위에 검색 줄이 나타나 그 목록만 거른다. 앱의 **모든 목록**에 적용한다(상단 제목줄 필터를 없애고, EKS·ArgoCD·Argo Workflows·Helm·보안 점검·접근·네트워크·로그 등 늘 보이던 목록 검색칸도 숨긴다).
- 검색 줄에서 Esc: 검색어를 지우고 줄을 닫는다(목록 전체가 다시 보인다).
- ⌘K: 지금처럼 앱 전체 리소스 찾기.
- EKS 목록에 k9s식 키를 넣는다(5번 탐색에서 구현, 사용자 정정 2026-11-04): 리소스 종류 이동은 `:pod`, `:deploy` 같은 명령 형식으로, 행 동작은 한 글자 키로(아래 표). 한 글자 키는 목록에 커서가 있고 입력칸·터미널·대화상자가 아닐 때만 동작한다. 바꾸는 동작(편집·삭제 등)은 키를 눌러도 바로 바뀌지 않고 지금처럼 미리보기부터 연다.
## 구조
- `src/keymap/keybindings.ts`: 고정 바인딩 표. 한 줄이 `{ key, command, when, label }`이다. 키 표기는 `cmd+f`, `shift+cmd+r`, `escape`처럼 VS Code와 같다. 이 표 하나가 디스패처, 단축키 보기 화면, 버튼 툴팁(`shortcutLabel(command)`)의 출처다.
- `src/keymap/registry.ts`: 명령 처리기 등록(`useCommand(command, handler, { host, enabled })`)과 창 하나의 keydown 디스패처. 키를 표에서 찾고, `when`을 지금 상태로 따져 맞는 바인딩의 명령을 처리기 하나에 넘긴다.
- 처리기 고르기: 같은 명령을 여러 화면이 등록하면 (1) 포커스가 들어 있는 host, (2) 마지막으로 누른(pointerdown) host, (3) 보이는 host 중 마지막에 등록한 것 순서로 하나만 부른다. 숨은 탭(보이지 않는 host)의 처리기는 부르지 않는다.
- `when` 문맥 키: `inputFocus`(입력칸·편집기에 커서), `dialogOpen`(모달), `terminalFocus`(xterm), `findOpen`(검색 줄에 커서), `textSelected`(글자를 고름). 처리기를 쓸 수 있는지(예: 프로필을 골랐는지)는 등록할 때 `enabled`로 정한다. 우선순위는 대화상자 > 편집기·터미널 > 목록·상세 > 탭 > 앱 전체이며, 위가 쓴 키는 아래로 넘기지 않는다.
- 목록 안의 ↑↓·Enter·Space 같은 이동 키는 지금처럼 목록 컴포넌트가 직접 처리한다(포커스 기반). 표에는 "목록" 범위로 올려 단축키 보기에 보이게만 한다.

## 바인딩 (고정)
| 키 | 명령 | 범위·조건 | 동작 |
|---|---|---|---|
| ⌘K | `app.findResource` | 프로필을 고름 | 앱 전체 리소스 찾기(지금과 같음) |
| ⇧⌘P | `app.commandPalette` | 늘 | 명령 팔레트: 지금 쓸 수 있는 명령과 그 단축키를 찾아 실행 |
| ⌘/ | `app.showShortcuts` | 늘 | 단축키 보기(지금 화면 범위의 키를 먼저, 검색 가능) |
| ⌘R | `app.refresh` | 늘 | 보고 있는 탭 다시 읽기 |
| ⇧⌘R | `app.hardReset` | 늘 | 리소스 캐시 모두 비우기 |
| ⌘F | `list.find` | 보이는 목록이 있음 | 그 목록 안쪽 위에 검색 줄을 열고 커서를 둔다(이미 열려 있으면 글자를 모두 고른다) |
| Esc | `list.findClose` | `findOpen` | 검색어를 지우고 검색 줄을 닫고, 커서를 목록으로 돌린다 |
| ↓·↑ (검색 줄에서) | `list.findToList` | `findOpen` | 목록으로 커서를 옮겨 첫 행(↓)·마지막 행(↑)을 고른다 |
| ↑·↓ | 목록 | 목록에 커서 | 행 이동 |
| Enter | 목록 | 목록에 커서 | 고른 행 열기 |
| Esc | `list.clearSelection` | 목록에 커서, 검색 줄 아님 | 선택 해제·상세 닫기 |
| ⌘[ · ⌘] | `tab.back` · `tab.forward` | 기록이 있는 탭(IAM·PG·탐색기) | 뒤로·앞으로 |
| ⌘C | `list.copyId` | 목록에서 행을 고름, 글자를 고르지 않음 | 고른 리소스 ID(S3는 `s3://` 주소) 복사 |
| Esc | `dialog.close` | `dialogOpen` | 맨 위 대화상자 하나만 닫기 |
| ⌘⎋ | `terminal.leave` | `terminalFocus` | 터미널에서 빠져나와 커서를 탭으로 돌린다(그 밖의 키는 모두 터미널로) |
| ⌘D · ⌘⌫ · Tab | `explorer.compare` · `explorer.delete` · `explorer.switchPane` | 파일 탐색기 | 지금과 같음 |
| F7 · ⇧F7 | `diff.next` · `diff.prev` | 비교 탭 | 지금과 같음 |
| `:` | `k8s.goto` | EKS 탭, `inputFocus` 아님 | (5번) 명령 줄: `:pod`·`:deploy`·`:svc`·`:no`처럼 k9s 별칭으로 종류 이동, `:ns <이름>` 네임스페이스 바꾸기, `:helm`·`:events` 등 메뉴 이동 |

### EKS 목록의 k9s식 한 글자 키 (5번 탐색에서 구현)
목록에 커서가 있고 입력칸·터미널·대화상자가 아닐 때만. 그 종류에서 쓸 수 없는 동작이면 아무것도 하지 않고 상태 줄에 이유를 잠깐 보인다. 바꾸는 동작은 모두 미리보기부터 연다.

| 키 | 대상 | 동작 |
|---|---|---|
| j · k | 모든 목록 | 아래·위 행(↓·↑와 같음) |
| g · G | 모든 목록 | 맨 위·맨 아래 행 |
| / | 모든 목록 | ⌘F와 같음(검색 줄 열기) |
| Enter | 워크로드 | 상세 열기(지금과 같음) |
| d | 모든 종류 | describe 형식 보기 |
| y | 모든 종류 | YAML 탭 |
| e | 모든 종류 | YAML 편집 |
| l | Pod·워크로드 | 로그 탭 |
| s | Pod | 셸 탭 / Deployment·StatefulSet: scale 미리보기 |
| a | Pod | attach |
| ⇧F | Pod·Service | 포트포워딩 줄로 커서 |
| r | Deployment·StatefulSet·DaemonSet | rollout restart 미리보기 |
| c · u | Node | cordon·uncordon 미리보기 |
| ⌃D | 모든 종류 | 삭제 미리보기 |
| 0 | 네임스페이스 있는 목록 | 모든 네임스페이스 |

## ⌘F 검색 줄
- 컴포넌트 `ListFind`와 훅 `useListFind(host)`: 목록마다 자기 검색 상태(열림, 검색어)를 갖고 `list.find`를 등록한다. 검색 방식은 지금의 퍼지 검색(`src/lib/fuzzy.ts`: 글자 일부를 순서대로, 공백으로 나누면 모두 맞는 것만)을 그대로 쓴다.
- 줄은 목록 상자 안쪽 맨 위에 붙는다(목록 머리글 위). 목록 옆 다른 거르개(체크박스, 칩, 그룹 선택)는 그대로 두고 글자 검색칸만 이 줄로 옮긴다.
- 목록이 둘인 화면(파일 탐색기 두 칸, EKS 목록 + 상세)은 포커스·마지막으로 누른 쪽 목록에 연다. 상세 안의 표(예: 이벤트)는 목록이 아니므로 대상이 아니다.
- 로그 보기의 검색도 같은 줄을 쓴다(로그 안에서 찾기).
- 탭을 옮겼다 돌아오면 그 목록의 검색 상태는 그대로다. 앱의 전역 `filter` 상태와 제목줄 입력칸은 없앤다.

## 단축키 보기와 명령 팔레트
- 단축키 보기(⌘/): 표를 범위별(앱, 지금 탭, 목록, 대화상자)로 보여 주고 검색할 수 있다. 지금 쓸 수 없는 키는 흐리게.
- 명령 팔레트(⇧⌘P): 등록된 명령 중 지금 `when`이 맞는 것을 이름으로 찾아 실행한다. 오른쪽에 단축키를 보인다. 키가 없는 명령(예: 서비스 설정 열기)도 실행할 수 있다.
- 버튼의 `title`에 바인딩이 있으면 `(⌘R)`처럼 키를 붙인다(표에서 읽는다).

## 정리하는 것
- 화면마다 따로 단 `window.addEventListener("keydown")` 전역 처리(App의 ⌘F·⌘K·⌘R·⇧⌘R, `useHistoryKeys`, ExplorerTab의 ⌘[·⌘]·⌘D·⌘⌫·Tab, `useCopyShortcut`, DiffTab F7)를 레지스트리 명령으로 옮긴다.
- Esc: `ConfirmDialog`와 `ArgoDetail`도 `useModal`처럼 맨 위 하나만 닫게 한다. 모든 목록 검색칸의 Esc가 같게 동작한다.

## 테스트
- 디스패처: 키 표기 해석, `when` 평가, 처리기 고르기 순서(포커스 > 마지막 누름 > 마지막 등록, 숨은 host 제외), 입력칸·대화상자·터미널에서 막히는 키.
- 표 자체: 같은 범위에서 같은 키가 두 명령에 묶이지 않는다.
- 화면: ⌘F가 보고 있는 목록에만 줄을 열고 그 목록만 거른다, Esc가 지우고 닫는다, 숨은 탭의 목록은 반응하지 않는다.
